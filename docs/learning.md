## Ruby / CLI

- CLIは `STDIN` から入力を受け取り、入力を解釈して処理を選び、`STDOUT` に結果を返せる。
- Rubyプロセス内の配列やHashに置いたデータは、そのプロセスが動いている間だけ利用できる。
- プロセス終了後もデータを残すには、ファイルやデータベースなどプロセス外へ永続化する必要がある。
- 外部入力は期待した形式とは限らないため、空文字、不正ID、未知のコマンドを扱う必要がある。

# playground

AIと一緒に、ソフトウェアの仕組みを「作る・壊す・理解する」ための技術実験リポジトリです。

コードをすべて手書きすることより、生成された実装について「なぜ動くのか」「何が隠蔽されているのか」「壊れたらどうなるのか」を説明できることを重視します。

## Focus

- Ruby / Java / C
- HTTP / TCP / API
- Database internals
- OS / memory / concurrency
- Search
- Distributed systems
- Real-time systems
- AI backends
